服务与设置

在线词典

需要你自己的授权凭据；Medict 不内置或分发受版权保护的词典内容。

Longman 等没有公开可自由分发的词典数据，当前可通过“打开在线词典”链接使用；后续可按正式授权增加适配器。

在线翻译

Google Cloud Translation 和有道智云会并行返回结果，凭据只保存在本机用户数据目录。

本地词典

支持 Medict JSON、常见 ECDICT CSV，以及每行“单词[TAB]释义[TAB]翻译”的 TXT。

医学信息提示

药物数据来自公开数据库，仅用于检索和研究整理，不构成诊断、处方或治疗建议。在线 API 可能有速率限制和服务条款。
