MEDICT

设置

划词后自动查词

打开后，鼠标选中文本并松开时自动查询；关闭后仍可使用“选词后查词”快捷键。

仅在 Medict 运行时监听，密码输入框会自动跳过。

快捷键

点击快捷键框后，直接按下新的组合键；按 Delete 可清除。

打开面板
选词后查词

默认：打开面板为 Ctrl + Alt + M；选中文本后查词为 Alt + D。

云端查词

单词优先返回完整在线词典，短语和句子自动补充翻译。

网页服务

单词调用有道网页词典，返回音标、英美发音、词性、多个义项、词形、词组和双语例句；短语或句子自动切换为网页翻译；无需填写 API Key。

免密钥

免密钥英文词典，自动返回音标、词性、多义项、例句和近反义词；启用百度词典版后优先显示百度的中英词典数据。

完整词典

百度官方词典版：英文释义、中文释义、音标、词性、例句和词形变化。需要在百度智能云开通“文本翻译-词典版”。

兼容模式便于直接试用，但接口可能随 Google 调整；正式发布可切换到 Cloud API。

词典服务顺序按此顺序显示

主面板会按此顺序显示在线词典和翻译结果，可用上下按钮调整。

字体大小

同步调整查词、翻译和药物结果的文字大小。

药物查询结果会自动保存在本机 30 天，相同查询优先读取缓存；点击结果右上角的刷新按钮可跳过缓存。

登录 Windows 后自动启动；仅对当前用户生效，不需要管理员权限。
